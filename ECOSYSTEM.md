# The Challenge -- из приложения в экосистему

Стратегия превращения трекера привычек в платформу. Ядро экосистемы -- не задачи и не стрики,
а **проверенное действие**: фотодоказательство, подтверждённое AI. Это примитив, которого нет
ни у одного конкурента, и вокруг него строится всё остальное.

---

## 1. Ядро: Verified Action как примитив

Каждый отчёт в `reports` -- это атом доверия: *человек X реально сделал Y в момент T, проверено AI*.
Всё в экосистеме либо производит такие атомы, либо потребляет их:

```
ПРОИЗВОДЯТ                    ЯДРО                      ПОТРЕБЛЯЮТ
iOS-камера          ─┐                              ┌─ Стрики и рейтинги
Telegram-бот        ─┤   reports + verify-report    ├─ Семейный дашборд
Коннекторы (Health, ─┤   (источник истины)          ├─ Отчёты в Notion
Strava, Calendar)   ─┘                              ├─ Челленджи со ставкой
                                                    └─ Внешний API
```

Принцип: **новые поверхности дешёвые, потому что ядро одно.** Telegram-бот уже доказал это --
он переиспользует те же reports и тот же verify-report.

## 2. Поверхности (где живёт пользователь)

| Поверхность | Статус | Следующий шаг |
|---|---|---|
| iOS-приложение | есть | виджеты + Live Activity на стрик дня |
| Telegram-бот | есть | прувы в группах: бот в семейном чате принимает фото от всех |
| Веб (thechallenges.app) | лендинг | веб-дашборд: история, статистика, шеринг профиля |
| Apple Watch | нет | отметка + фото с iPhone по пушу |
| Виджеты iOS | нет | «сегодня N/3», кольцо стрика |

## 3. Коннекторы -- нервная система (реализовано в этом релизе)

Данные **входят** (Health, Fitness, Strava, Whoop, календари -- автоподтверждение метрик,
меньше ручных фото) и **выходят** (Notion/Google Docs -- еженедельные отчёты, Gmail -- дайджесты,
календарь -- планирование задач). Free-уровень покрывает быт, Max-уровень -- power-юзеров
и создаёт прямой мотив для тарифа Challenge Max.

Дальше: webhooks наружу («стрик сгорел» → IFTTT/Zapier), импорт целей из Notion-базы.

## 4. Социальный слой: от семьи к графу

Семья (есть) -> **Группы**: челленджи с друзьями («30 дней бега», общий рейтинг, прувы видны
группе) -> **Публичные челленджи**: куратор публикует программу, тысячи участников, лидерборды ->
**Ставки на себя**: депозит, который сгорает при провале (соцфонд группы забирает) -- сильнейшая
механика удержания.

Ключ: прув с фото -- это уже готовый социальный контент. Лента группы = лента доказательств,
не лента обещаний.

## 5. Экономика

- **Подписки** (готово): Free -> Premium (месяц/год/навсегда) -> Family -> Max.
- **Маркетплейс программ**: авторы (тренеры, коучи) публикуют платные программы челленджей
  с AI-проверкой; комиссия платформы 20-30%. Это превращает пользователей в дистрибуцию.
- **B2B**: корпоративные велнес-челленджи (команда, дашборд HR, обезличенная статистика).

## 6. Платформа: Challenge API

«**Verified by Challenge**» -- внешние продукты принимают наши верификации:
языковая школа засчитывает домашку по пруву, фитнес-клуб даёт скидку за стрик.
API: OAuth-приложения, scope `read:streaks read:reports`, webhooks. Max-подписчики
получают персональные API-токены первыми.

## 7. AI-коуч как связующая ткань

morning-brief / analyze-failure / split-goal уже есть. Следующий уровень -- коуч, который видит
ВСЁ: прувы, Health-метрики, календарь, провалы -- и ведёт диалог в Telegram. Память коуча --
главный switching cost экосистемы: чем дольше пользователь внутри, тем дороже уходить.

## Дорожная карта

1. **Сейчас (готово):** 6 тарифов, коннекторы Free/Max, выровненный rate limiter.
2. **Квартал:** виджеты, веб-дашборд, групповые челленджи в Telegram, экспорт отчётов в Notion.
3. **Полгода:** публичные челленджи + ставки, маркетплейс программ (бета), webhooks.
4. **Год:** Challenge API + «Verified by Challenge», B2B-пилоты, watch-приложение.

Метрика экосистемы одна: **число поверхностей, которых касается пользователь за неделю.**
1 поверхность -- churn-риск; 3+ -- удержание решено.
